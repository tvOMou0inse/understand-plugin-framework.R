# jankenpo em Node com Express

### Note

Vale conferir a versao instalada antes de seguir os passos abaixo.


## Demonstração

Há uma gravação do jogo em funcionamento.

## Instalação

Depois de instalar o runtime e o gerenciador de pacotes, conforme a página oficial da linguagem.

Na raiz do projeto rode a instalação das dependências:

> npm install

## Execução

Primeiro suba a aplicação:

```
> node index.js
```

Depois abra no navegador um endereço como:

```
http://127.0.0.1:3000/?choice=paper
```

Troque a escolha no parâmetro final, podendo ser pedra, papel ou tesoura.
